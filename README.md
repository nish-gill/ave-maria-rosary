# Ave Maria Rosary

A Rosary prayer app in 12 languages, with the mysteries, Scripture, meditations
and optional prayer methods based on St. Louis de Montfort.

## Run it on your computer

Requires [Node.js](https://nodejs.org) 18 or newer.

```
npm install
npm run dev
```

Then open the address it prints (usually http://localhost:5173).

## Build for publishing

```
npm run build
```

The finished site is in the `dist` folder. On Cloudflare Pages or Netlify, use
build command `npm run build` and output folder `dist`.
